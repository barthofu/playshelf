# Concept

> Like Plex, but for your DRM-free video game collection

The goal of this project is to provide a self-hosted and centralized game library that you populate yourself, alongside a great desktop client to download and install games from it on the fly.

The client should be able to run and be used even without a connection to a PlayShelf server. In fact, by default the client should be something similar to GOG Galaxy, with third parties integrations like Steam or Epic Launcher login to import your own games from it.

In addition of that, you can connect to one or multiple hosted PlayShelf libraries.
